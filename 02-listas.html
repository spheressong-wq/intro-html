Sobre elementos de lista

Listas são uma das coisas mais importantes e simples do HTML. Elas aparecem o tempo todo em casa. Elas aparecem o tempo todo em sites.

Conhecendo as listas

Lista não ordenada (UL)

Usamos a lista não ordenada quando a ordem dos itens não importa.

  • Leite
  • Banana
  • Pão
  • Café

Lista ordenada (OL)

Aqui, nessa estrutura, a ordem como os itens são apresentados na tela importa.

  1. Comprar igredientes
  2. Misturar igredientes
  3. Colocar no forno
  4. Comer

Lista de descrição (DL)

Esse tipo de lista serve para representarmos termos e usas respectivas descrições.

DT = Data term
HTML
Linguagem utilizada para estruturar páginas da web.
CSS
Linguagem utilizada para estilizar páginas da web.
Java script
Linguagem utilizada para adicionar comportamentos ao HTML, que é a mesma coisa que páginas da web.
